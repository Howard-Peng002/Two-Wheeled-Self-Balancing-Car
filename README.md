# 平衡小车 (STM32F103 自平衡小车)

本项目提供两套基于 STM32 标准外设库的固件实现：
- 标准库：裸机版。 MPU6050 的 INT 外部中断以约 100 Hz 触发，并在中断中完成姿态读取、直立环＋速度环＋转向环计算和电机输出；主循环处理蓝牙遥控、在线调参、超声波避障及显示。
- RTOS：FreeRTOS 版。 MPU 中断只通知高优先级平衡任务，由任务执行上述控制计算；蓝牙、超声波导航和 OLED 显示分别由其他任务处理。它沿用相同的硬件接线、默认参数和 App 协议。详细见RTOS目录中readme.md文件。

## 功能特性

- **自平衡**：直立环（PD）+ 速度环（PI）+ 转向环，串级 PID
- **姿态解算**：MPU6050 内置 DMP，控制环由 INT 引脚中断触发，频率 100Hz
- **蓝牙遥控**：HC-06 经典蓝牙（SPP），前进 / 后退 / 左转 / 右转 / 急停
- **蓝牙在线调参**：7 个 PID 参数下发即生效，无需重烧固件
- **参数回读**：`show` 命令回读全部参数，手机端能确认当前实际值
- **超声波避障**：分级减速 + 近距停车 + 迟滞恢复，避免在阈值附近反复启停
- **自动模式**：超声测距自主前进，遇障刹车，再转向绕过
- **本地显示**：OLED 显示车身角度、前方距离、轮速
- **安全保护**：倾角偏离机械中值超过 60° 立即切断电机输出

## 接线说明

引脚以下全部与固件里的配置一一对应。

| STM32 引脚 | 接到 | 说明 |
| --- | --- | --- |
| PB10 | HC-06 RXD | USART3_TX，主控发送 |
| PB11 | HC-06 TXD | USART3_RX，主控接收 |
| PB8 | OLED SCL | 软件 I2C 时钟 |
| PB9 | OLED SDA | 软件 I2C 数据 |
| PB4 | MPU6050 SCL | 软件 I2C 时钟 |
| PB3 | MPU6050 SDA | 软件 I2C 数据 |
| PB5 | MPU6050 INT | 下降沿中断，控制环的触发源 |
| PA3 | 超声波 TRIG | 触发输出 |
| PA2 | 超声波 ECHO | 回响输入 |
| PA0 / PA1 | 左编码器 A / B 相 | TIM2 编码器模式 |
| PB6 / PB7 | 右编码器 A / B 相 | TIM4 编码器模式 |
| PA8 | 电机驱动 PWMA | TIM1_CH1，左轮 |
| PA11 | 电机驱动 PWMB | TIM1_CH4，右轮 |
| PB14 / PB15 | 电机 A 方向 IN1 / IN2 | 推挽输出 |
| PB13 / PB12 | 电机 B 方向 IN1 / IN2 | 推挽输出 |
| PA9 / PA10 | 调试串口 TX / RX | USART1，默认 printf 不走这里 |
| 5V / GND | 各模块 VCC / GND | 必须共地 |

⚠️ **蓝牙模块 TXD / RXD 交叉**：模块 TXD → 主控 PB11，模块 RXD → 主控 PB10。

## 快速开始
### 1. 安装手机 App

App 工程在 `蓝牙调参App/`，用 Android Studio 打开直接编译安装即可。

命令行方式：

```bash
export JAVA_HOME=/c/Users/asus/Jdk17
export ANDROID_HOME='C:\Users\asus\AndroidSdk'
./gradle-8.5/bin/gradle -p "蓝牙调参App" --no-daemon assembleDebug
```

产物 `蓝牙调参App/app/build/outputs/apk/debug/app-debug.apk`，用 adb 安装：

```bash
adb install -r app-debug.apk
```

## 使用说明

### 手机端操作

1. **上电**：小车 OLED 显示角度、距离、轮速
2. **连蓝牙**：App 里搜索并连接 `HC-06`（默认配对码 `1234`），已连接过的会自动重连
3. **先点「手动」按钮**，再按方向按钮
4. **遥控**：前进 / 后退 / 左转 / 右转，急停按钮随时刹车
5. **调参**：拖动滑块，松手时自动下发
6. **自动模式**：点「自动」按钮，小车会用超声波自主前进避障

### 遥控命令

| 命令 | 作用 |
| --- | --- |
| `f` / `b` / `l` / `r` | 前进 / 后退 / 左转 / 右转 |
| `s` | 刹车，同时清除速度环积分 |
| 单字节 `0x01` / `0x05` / `0x07` / `0x03` | 同上四个方向|

### 调参命令

| 命令 | 参数 | 量程 |
| --- | --- | --- |
| `vk=` | 直立环 Kp | -1000 ~ 0 |
| `vd=` | 直立环 Kd | -10 ~ 0 |
| `vp=` | 速度环 Kp | 0 ~ 1 |
| `vi=` | 速度环 Ki | 0 ~ 0.05 |
| `td=` | 转向环 Kd | 0 ~ 2 |
| `tp=` | 转向环 Kp | 0 ~ 100 |
| `ma=` | 机械中值（度） | -20 ~ 20 |

直立环的两个参数是**负数**，本车前进时 Pitch 读数为负。

### 其它命令

| 命令 | 作用 |
| --- | --- |
| `show` | 回读全部参数，返回一行 `#vk=... vd=... ...` |
| `ping` | 连通性测试，返回 `#pong` |
| `rst` | 清除速度环积分量 |
| `mode=manual` | 切手动模式 |
| `mode=auto` | 切自动模式 |
| `mode=off` | 关闭运动控制 |
| `mode?` | 查询当前模式与状态 |
| `auto=start` / `auto=stop` | 自动模式下起停 |
| `csv` | 波形回传从二进制改回文本格式 |
| `raw` | 把上一包二进制数据按十六进制打出来，协议对不上时排查用 |

## 控制原理

控制环跑在 MPU6050 的 INT 中断里（`EXTI9_5_IRQHandler`），每个中断周期执行一次：

```
读编码器 → 读 DMP 姿态 → 速度环(PI) → 直立环(PD) → 转向环 → 合成 PWM → 驱动电机
```

- **速度环**输出的是"目标倾角修正量"，不是直接给电机的 PWM，最终限幅在 ±8°
- **直立环**的目标角度 = 机械中值 + 速度环输出
- **转向环**输出差速叠加到左右电机上：
  - 左电机 = 直立环输出 − 转向环输出
  - 右电机 = 直立环输出 + 转向环输出

控制环放在中断里而不是主循环，是因为主循环里有超声波测距（每次几百毫秒）和 OLED 刷新，放主循环里控制周期会飘。中断优先级上，控制中断（抢占 0）高于串口中断（抢占 2），所以串口收到的字节只在中断里入缓冲，解析放到主循环做。
